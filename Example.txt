3. Input & Output Structure (Using the Teammate Pipeline Example)
Using the Appendix C.1 sample (teammate_pipeline.py) as the placeholder input:

Input (code: str)
python


raw_logs = [
    {"user": " alice ", "action": "login", "status": 200},
    {"user": "bob", "action": "upload", "status": 500},
    {"user": "", "action": "ping", "status": 200},
    {"user": "charlie", "action": "logout", "status": 200}
]
cleaned_records = []
error_count = 0
for record in raw_logs:
    name = record["user"].strip().capitalize()
    if len(name) > 0:
        if record["status"] >= 400:
            error_count += 1
        cleaned_records.append({
            "user": name,
            "action": record["action"],
            "success": record["status"] < 400
        })
summary = {
    "total_valid": len(cleaned_records),
    "total_errors": error_count
}
print("Summary:", summary)

How Stage 4 uses this output
In Stage 4 (tracer.py), when execution reaches line 12:

The tracer checks flow_index.loops.get(12).
It immediately knows this is a for loop targeting record.
It packages that into the loop_context field matching the TraceStep placeholder in 
backend/app/routers/trace.py
